## Building a Web Application for a Wedding Dress Rental Business using Python Django ##
![dressapp](https://github.com/tonytsoi/wedding_dresses/blob/master/WeddingDressApp.jpg)

I have recently built a web application using the Django framework in Python for a wedding dress rental business. This app would serve as a photo catalogue for all the dresses available in the shop, as well as helping the business to keep track of the dresses in its inventory and manage bookings.

The web app would be hosted for a limited period of time <a href="http://weddingdressesapp-env.eba-bssmab7i.us-east-2.elasticbeanstalk.com/">here</a>.

For more details, please refer to this article <a href="https://medium.com/@tsoiyingkit/building-a-web-application-for-a-wedding-dress-rental-business-using-python-django-342563ce77d8">here</a>, which I would first present an overview of the Django framework, then further discuss how I have built the web app, and lastly how to deploy the app onto the Amazon Web Services (“AWS”) platform.
